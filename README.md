# 48-3rd-TeamHongC-backend
최홍, 박건률, 김민수, 임홍규, 김수영
### 기술스택 정보
- Node.js
- Typeorm
- MySQL
- JavaScript

---

## 📁 프로젝트 구조 및 개요

- **초기 세팅**: 기본적인 프로젝트 구조 설정 (2023-09-06 ~ 2023-09-07)
- **DB 설계 및 수정**: `locations`, `payment`, `purchase_item` 등 다양한 테이블 설계 및 수정
- **인증 및 인가 기능**: 소셜 로그인, 페이지 권한 처리
- **검색 기능**: 다수의 커밋에서 검색 API 기능 반복 구현 및 개선
- **아이템 기능**: 아이템 생성 및 전체 조회 기능
- **마이페이지**: 사용자 마이페이지 기능 구현
- **후기 및 좋아요 기능**: 리뷰 리스트 및 좋아요 처리 구현
- **카카오페이 연동**: 카카오페이 결제 API 연동 및 리스트 구현
- **코드 리팩토링**: 전반적인 코드 정리 및 구조 개선

---

## 🚀 주요 기능

| 기능 구분 | 설명 |
| -------- | ---- |
| 사용자 인증 | 소셜 로그인 구현 (카카오 등) |
| 검색 기능 | 다양한 조건의 검색 API |
| 아이템 | 아이템 등록 및 조회 |
| 리뷰 | 사용자 리뷰 리스트 처리 |
| 좋아요 | 좋아요 처리 기능 |
| 마이페이지 | 사용자 개인화 페이지 |
| 결제 | 카카오페이 연동, 결제 리스트 처리 |
| DB | 테이블 설계 및 리팩토링 |
| 인가 | 페이지 접근 권한 처리 |
| 리팩토링 | 코드 정리 및 성능 개선 |
